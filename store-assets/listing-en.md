## Description (4000)

```
Rocktier Markdown is a fast, elegant Markdown editor for macOS. You type on one side and the page renders on the other — the preview never makes you wait, because it is not allowed to.

WRITE AND READ IN ONE WINDOW
Split view with live rendering while you type, or a clean full-width reading mode when you want the page and nothing else. The sidebar holds your recent files and a live outline of the document's headings; hide it and the text takes the whole window.

BUILT FOR LONG DOCUMENTS
Jump to any section from the outline. Search inside the document with next and previous, replace one match or all of them. The current section is tracked as you scroll, so you always know where you are in a two-hundred-page file.

SAVES THAT DON'T LOSE WORK
Writes go to a temporary file and are then renamed into place, so an interrupted save cannot truncate your document. If a session is cut short, what you had is still there rather than half-written.

EXPORT WHEN YOU'RE DONE
Print, or export to PDF through the system print dialog. There is no bundled print engine and no hidden pagination of its own — the PDF is the one macOS shows you.

READS EVERYTHING
CommonMark plus the GitHub extensions people actually use: tables, task lists, strikethrough, autolinks, footnotes. Code blocks are highlighted, math renders inline.

OPENS FROM ANYWHERE
Markdown files are registered with the system, so Rocktier Markdown appears in "Open with" and can be set as the default handler. Drag a file onto the window to open it.

MADE FOR macOS
Native menu bar and shortcuts, light and dark themes, English and 简体中文 switchable at runtime, and an interface that stays out of the way of the text.

PRIVATE BY DESIGN
Your documents never leave your Mac. There is no account, no telemetry and no cloud storage. Reading, writing and exporting all work fully offline.

Part of the Rocktier family of small, fast, private Mac tools, alongside Rocktier PDF, Rocktier CAD Viewer, Rocktier pic2webp and Rocktier OCR.
```
